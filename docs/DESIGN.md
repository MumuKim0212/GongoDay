# 디자인 규칙 — 오늘공고

목업(`mockup/오늘공고.dc.html`)이 쓰는 **Broadsheet** 디자인 시스템을 이 프로젝트에 옮기는 규칙이다.
원본은 `mockup/_ds/broadsheet-01d703a1-1331-4b61-a14b-b744189e8823/` — `readme.md`(지침)와 `styles.css`(토큰)가 원전이다.

**이 문서의 목적은 하나다: 화면을 여러 번에 나눠 고쳐도 같은 결과가 나오게 하는 것.**
색·크기·여백을 고를 일이 생기면 여기서 찾고, 여기에 없으면 여기에 먼저 적고 나서 코드를 고친다.

작업 전에 정한 네 가지다. 이유는 §7에 있다.

## §1 원칙

Broadsheet은 **웹에 올린 신문 조판**이다. 종이색 바탕에 먹빛 세리프, 공정 잉크(시안·마젠타)를 스팟 컬러처럼 아주 조금.

1. **박스와 선으로 구조를 만들지 않는다.** 위계는 글자 크기와 여백이 만든다.
2. **전부 세리프다.** UI 크롬에 산세리프를 섞지 않는다.
3. **시안이 상호작용, 마젠타는 더 드문 두 번째 스팟.** 한 작은 컴포넌트에 두 잉크를 같이 쓰지 않는다.
4. **왼쪽 정렬, 비대칭.** 내용은 왼쪽에 붙고 오른쪽에 여백이 남는다.
5. **여백 스케일을 좁히지 않는다.** 밀도 1.25배가 이미 토큰에 박혀 있다.

### 이 프로젝트에서 지금 어긋나 있는 것

현재 코드가 원칙을 어기는 지점이다. 고칠 목록이기도 하다.

| 어긋난 곳 | 지금 | 고칠 방향 |
|---|---|---|
| 목록 카드 구분 | `border-b`로 행을 나눔 ([PolicyCard.tsx:33](../src/components/PolicyCard.tsx:33)) | `.card` + 여백 간격 (원칙 1) |
| 상세 화면 블록 | 섹션마다 `rounded border` 박스 | 판정 블록만 `.card`, 나머지는 여백 (원칙 1) |
| 서체 | `Arial, Helvetica, sans-serif` ([globals.css:25](../src/app/globals.css:25)) | 세리프 페어링 (원칙 2) |
| 배지 색 | `emerald`·`sky`·`green`·`teal`·`amber`·`slate` 6계열 | 시안·마젠타·중성 3계열 (원칙 3) |
| 관리자 막대 | Tailwind 기본 `gray-*` | 토큰 상속만 (범위 밖, §5.4) |

### Broadsheet에서 의도적으로 벗어나는 것

**일탈은 아래 다섯 개뿐이다.** 여기 없는 일탈이 코드에 있으면 그건 버그다.

| # | 일탈 | 왜 |
|---|---|---|
| D1 | 다크 모드를 추가한다 | 원본은 "no dark surfaces". 사용자 결정으로 유지 — 램프에서 파생한다 (§2.1) |
| D2 | 한글 조판 보정 (서체 페어링 · 최소 12px · 행간 1.7) | Source Serif 4에 한글 글리프가 없다. 원본의 10~11px 단계는 한글에서 읽히지 않는다 (§2.3) |
| D3 | 토큰을 Tailwind `@theme`로 내린다 | 원본은 순수 CSS 클래스. 기존 코드가 전부 Tailwind다 (§2.6) |
| D4 | 채움 배경의 잉크는 `accent` 대신 `accent-700` | `accent`(#0088b0)와 종이색의 대비가 3.7:1 — 작은 글자 AA(4.5:1) 미달. `accent-700`은 5.7:1 (§6.1) |
| D5 | 5단계 점수 배지를 잉크 농도 계단으로 만든다 | 원본 태그는 4종인데 이 서비스는 5단계가 필요하다 (§4.1) |

## §2 토큰

### §2.1 색 ✅

역할 토큰만 쓴다. 램프 값을 컴포넌트에 직접 박지 않는다.

| 역할 | 라이트 | 다크 | 쓰는 곳 |
|---|---|---|---|
| `bg` | `#f3f2f2` 종이 | `#201e1d` 먹 | 페이지 바탕 |
| `surface` | `#eae9e9` | `#2d2b2b` (neutral-900) | 카드·입력칸 채움 |
| `text` | `#201e1d` | `#f3f2f2` | 본문 |
| `text-muted` | text 70% | text 70% | 힌트·메타·보조 설명 (§6.1) |
| `text-faint` | text 55% | text 55% | 장식용 캡션. **읽어야 하는 정보에 쓰지 않는다** |
| `accent` | `#0088b0` 시안 | `#99e0ff` (accent-300) | 링크·아이콘·큰 글자·테두리 |
| `accent-ink` | `#006786` (accent-700) | `#99e0ff` (accent-300) | **채움 배경**의 잉크 (D4) |
| `accent-2` | `#d6006c` 마젠타 | `#ffc0d0` (accent-2-300) | 두 번째 스팟 |
| `divider` | text 16% | text 16% | 꼭 필요한 한 줄. 기본은 여백 |

**다크는 종이와 먹을 뒤집은 것이다.** 먹이 바탕이 되고 종이가 글자가 된다 — "잉크 위에 인쇄한 종이".

램프는 원본 `styles.css`의 값을 그대로 가져온다 (neutral / accent / accent-2 × 100~900). 사용 규칙:

| | 라이트 | 다크 |
|---|---|---|
| 옅은 채움·호버 | 100~300 | 800~900 |
| 기준 | 500 | 300~400 |
| 채움 위 글자·눌림 | 700~900 | 100~300 |

`--color-process-yellow`(#edbb00)는 **인쇄 처리 전용**이다. 본문·크롬·배지에 쓰지 않는다.

### §2.2 그림자 ✅

| | 라이트 | 다크 |
|---|---|---|
| `sm` | `0 1px 2px` 먹 14% | 헤어라인 테두리 + `0 1px 2px` 검정 40% |
| `md` | `0 3px 10px` 먹 16% | 헤어라인 + `0 3px 10px` 검정 45% |
| `lg` | `0 12px 32px` 먹 22% | 헤어라인 + `0 12px 32px` 검정 55% |

다크에서 그림자는 어둠으로 안 보인다. 원본 주석이 말하는 대로 **헤어라인 테두리 + 주변 어둠**으로 바꾼다.

### §2.3 타이포 ✅

```
--font-heading: "Source Serif 4", "Noto Serif KR", system-ui, serif   (600)
--font-body:    "Source Serif 4", "Noto Serif KR", system-ui, serif   (400)
```

**Source Serif 4를 앞에 둔다.** 라틴·숫자는 Source Serif 4가 잡고, 한글은 글리프가 없으므로 Noto Serif KR로 넘어간다. 순서를 바꾸면 숫자까지 Noto가 가져간다.

스케일 — 원본 스케일에서 실제로 쓰는 단계만 고정한다. **여기 없는 크기를 쓰지 않는다.**

| 이름 | 크기 | 행간 | 용도 |
|---|---|---|---|
| `display` | 32px / 600 | 1.12 | 첫 방문 안내 제목 |
| `title` | 25px / 600 | 1.12 | 화면 제목 (목록 h1, 상세 h1) |
| `section` | 20px / 600 | 1.2 | 섹션 제목 (h2) |
| `sub` | 16px / 600 | 1.2 | 소제목 (h3) |
| `body` | 15px / 400 | **1.7** | 본문 |
| `compact` | 14px / 400 | 1.55 | 카드 안 짧은 글, 버튼·입력칸 |
| `small` | 13px / 400 | 1.6 | 보조 설명·힌트 |
| `micro` | **12px** / 400 | 1.4 | 배지·메타·키커. **이보다 작게 쓰지 않는다** |

**D2 보정 세 가지:**
- 본문 행간을 1.55 → **1.7**. 한글은 글자마다 밀도가 높아 원본 행간에서 뭉친다.
- 최소 크기를 10~11px → **12px**. 원본 `.card-kicker`(10px)·`.tag`(11px)·`figcaption`(11px)이 전부 12px로 올라간다.
- 키커는 `text-transform: uppercase`를 걸지 않는다 — 한글에 효과가 없다. `letter-spacing: 0.08em`만 남긴다.

숫자는 배지·통계에서 `tabular-nums`. 강조·인용은 Source Serif 4의 **진짜 이탤릭**을 쓴다 (합성 기울임 금지).

### §2.4 여백 ✅

**Tailwind의 `--spacing`을 `5px`로 놓으면 Broadsheet 스케일과 정확히 일치한다.**

Tailwind 기본값은 `0.25rem`(4px)이고 Broadsheet은 5·10·15·20·30·40 — 5px × n이다. 원본이 말하는 "density 1.25×"가 곧 `4px × 1.25 = 5px`이다.

| Broadsheet | 값 | Tailwind |
|---|---|---|
| `--space-1` | 5px | `p-1` `gap-1` `mt-1` |
| `--space-2` | 10px | `-2` |
| `--space-3` | 15px | `-3` |
| `--space-4` | 20px | `-4` |
| `--space-6` | 30px | `-6` |
| `--space-8` | 40px | `-8` |

> ⚠️ 이 한 줄이 **기존 코드의 모든 여백 유틸리티를 1.25배로 늘린다.** 의도한 결과다. 다만 `w-44`·`h-*` 같은 **고정 크기 유틸리티도 같은 스케일을 타므로** 폼 입력칸 폭은 구현 때 다시 본다 (§8).

컨테이너 폭 — 목업을 따른다.

| 화면 | 폭 |
|---|---|
| 목록 (`/`) · 헤더 | 1040px |
| 상세 (`/policies/[id]`) | 680px |
| 프로필 (`/profile`) | 680px |

### §2.5 반경 ✅

`sm 1px` / `md 2px` / `lg 4px`. 태그는 `md × 0.75`.
Tailwind의 `--radius-*`를 덮으므로 `rounded-sm`/`rounded-md`/`rounded-lg`만 쓴다. **접미사 없는 `rounded`는 쓰지 않는다** (덮이지 않는 기본값이라 스케일 밖으로 나간다).

### §2.6 globals.css 구조 🟡

```css
@import "tailwindcss";

/* 1. 원색 — 라이트/다크가 여기서 갈린다 */
:root {
  --paper: #f3f2f2;  --ink: #201e1d;  --surface: #eae9e9;
  --accent: #0088b0; --accent-ink: #006786; --accent-2: #d6006c;
  /* 램프 27개는 원본 styles.css에서 그대로 */
}
@media (prefers-color-scheme: dark) {
  :root {
    --paper: #201e1d;  --ink: #f3f2f2;  --surface: #2d2b2b;
    --accent: #99e0ff; --accent-ink: #99e0ff; --accent-2: #ffc0d0;
  }
}

/* 2. @theme inline — 값이 아니라 var()를 참조해야 다크가 런타임에 뒤집힌다 */
@theme inline {
  --color-bg: var(--paper);
  --color-text: var(--ink);
  /* … */
  --spacing: 5px;
  --radius-sm: 1px; --radius-md: 2px; --radius-lg: 4px;
  --font-heading: "Source Serif 4", "Noto Serif KR", system-ui, serif;
}

/* 3. 컴포넌트 레이어 — §3 */
@layer components { /* .btn .tag .card … */ }
```

**`@theme inline`이어야 한다.** `@theme`은 값을 복사해 넣으므로 미디어 쿼리로 뒤집어도 유틸리티가 따라오지 않는다.

> ⚠️ **손으로 쓰는 CSS는 `--color-*`·`--text-*`를 쓰면 안 된다.** Tailwind는 유틸리티가 실제로 쓰지 않는 테마 변수를 `:root`에 내보내지 않는다 — 브라우저에서 확인한 결과 `--color-muted`와 `--text-body`는 **빈 문자열**이었다. 컴포넌트 레이어(§3)는 `--paper`·`--ink`·`--accent-ink`·`--muted`·`--bs-*`처럼 우리가 `:root`에 직접 선언한 이름만 쓴다. 이것이 토큰을 두 층으로 나눈 실질적인 이유다.

여백도 한 곳에서 나온다. `:root`의 `--space-unit: 5px`를 `@theme`의 `--spacing`이 참조하므로, 유틸리티(`p-3`)와 컴포넌트 레이어(`calc(var(--space-unit) * 3)`)가 같은 값을 쓴다.

**컴포넌트에 `dark:`를 쓰지 않는다.** 다크 대응은 토큰이 한다. 지금 코드에 깔린 `dark:` 변형은 전부 지운다 — 토큰이 뒤집히므로 필요 없다. 구조 자체가 달라져야 하는 예외만 `dark:`를 남기고, 그때는 이 문서에 적는다.

## §3 컴포넌트 레이어 ✅

**클래스로 만드는 것은 세 개뿐이다** — 여러 화면에서 반복되고, 상태(hover/active/focus)를 함께 들고 다녀야 하는 것들.

| 클래스 | 변형 | 쓰는 곳 |
|---|---|---|
| `.btn` | `-primary` `-secondary` `-ghost` `-block` | 모든 버튼·버튼처럼 보이는 링크 |
| `.tag` | `-solid` `-accent` `-accent-2` `-neutral` `-outline` `-quiet` | 배지 전부 |
| `.card` | `-kicker` `-title` `-body` `-meta` / `.elev-sm` | 목록 카드, 판정 블록 |

그 외(레이아웃·간격·1회성 스타일)는 전부 Tailwind 유틸리티다.

입력칸(`.input`)·라디오·세그먼트는 원본 `styles.css`의 정의를 그대로 옮기되, **쓰는 단계에서 만든다** — 목록의 검색창은 §9 4단계, 프로필 폼은 6단계다. 안 쓰는 CSS를 미리 깔지 않는다.

### 상태 ✅

원본 규칙 그대로. **브라우저 기본값을 남기지 않는다.**

| 상태 | 라이트 | 다크 |
|---|---|---|
| hover (채움) | `accent-800` | `accent-200` |
| active (채움) | `accent-900` | `accent-400` |
| hover (외곽선·고스트) | 잉크 7% 틴트 | 종이 10% 틴트 |
| focus-visible | `outline: 2px solid var(--color-accent); outline-offset: 2px` | 같음 |
| hover·active 적용 대상 | `:not(:disabled)`에만 — 비활성 버튼이 hover에 반응하면 눌리는 것처럼 읽힌다 | 같음 |
| disabled | `opacity: 0.45` | 같음 |
| `::selection` | accent 30% | 같음 |

## §4 이 프로젝트 고유의 결정

목업에 답이 없거나, 이 서비스에만 있는 것들이다.

### §4.1 5단계 점수 배지 ✅ (D5)

점수는 확인 항목 수에서 유도된다 ([score.ts](../src/lib/verdict/score.ts)). 원본 태그는 4종인데 5단계가 필요하다.

**색조로 5단계를 만들지 않는다. 잉크 농도로 만든다.** 신문 조판이 등급을 표현하는 방식이고(원본이 말하는 "black-and-white wedge"), 색맹 사용자에게도 순서가 남는다.

| 점수 | 표시 | 클래스 | 라이트 | 다크 | 잉크 | 대비(라이트/다크) |
|---|---|---|---|---|---|---|
| **5** 신청 가능 | `5 신청 가능` | `.tag-solid` | 채움 `accent-700` / 글자 종이색 | 채움 `accent-300` / 글자 먹색 | 가득 참 | 5.72 / 11.43 |
| **4** 확인 1개 | `4 확인 1개` | `.tag-accent` | `accent-100` / `accent-800` | `accent-900` / `accent-200` | 옅은 시안 | 9.10 / 11.44 |
| **3** 확인 N개 | `3 확인 N개` | `.tag-accent-2` | `accent-2-100` / `accent-2-800` | `accent-2-900` / `accent-2-200` | 옅은 마젠타 | 9.85 / 11.72 |
| **2** 조건 미기재 | `2 조건 미기재` | `.tag-neutral` | `neutral-200` / `neutral-800` | `neutral-800` / `neutral-200` | 중성 | 8.22 / 8.22 |
| **1** 아님 | `1 아님` | `.tag-quiet` | 테두리 `neutral-400` / 글자 `neutral-700` | 테두리 `neutral-700` / 글자 `neutral-400` | 비어 있음 | 5.83 / 8.27 |

- **채움은 5점 하나뿐이다.** 목록에서 "볼 게 있는지"가 한눈에 잡힌다.
- 3점에 마젠타를 쓰는 것은 "나쁨"이 아니라 **"여기를 봐야 함"**이다. 4점(시안)과 3점(마젠타)은 잉크가 다르지만 둘 다 옅다 — 농도가 서열이고 색은 성격이다.
- 한 배지 안에 잉크는 하나다 (원칙 3). `· 코드`/`· AI` 꼬리표는 같은 잉크의 70% 불투명도.
- **대비는 위 표의 실측값이다** (2026-08-06, 브라우저에서 계산). 가장 낮은 것이 5점 채움 5.72:1과
  1점 5.83:1 — 둘 다 AA(4.5:1)를 넘는다. 나머지는 8:1 이상이다.

### §4.2 출처 표시 ✅

`emerald`/`sky` 두 색으로 나누던 것을 **`.card-kicker` 한 형태로 통일한다** — 목업이 쓰는 방식이다.

```
온통청년          ← 12px, letter-spacing 0.08em, accent 잉크
서울 청년 월세 지원사업   ← card-title
```

**두 소스 모두 같은 잉크다.** 구분은 글자가 한다. 색을 하나 더 쓰면 판정 배지의 시안·마젠타와 경쟁한다.

### §4.3 인용 하이라이트 ✅

노란색을 쓰지 않는다. **`accent-100` 배경 / `accent-800` 글자** (다크: `accent-900` / `accent-200`) — 목업 스크립트가 쓰는 값 그대로다.

> ⚠️ [policies/[id]/page.tsx:215](../src/app/policies/[id]/page.tsx:215)의 안내문이 **"노란 표시가 판정 근거로 인용된 문장입니다"**라고 말한다. 색을 바꾸면 이 문장도 함께 고쳐야 한다 — `"표시된 문장이 판정 근거로 인용된 문장입니다"`.

`--color-process-yellow`는 인쇄 처리 전용이라 여기 쓸 수 없다 (§2.1).

### §4.4 그 밖의 배지 ✅

| 대상 | 클래스 |
|---|---|
| 분야 (주거·일자리…) | `.tag-neutral` |
| 조건 밖 | `.tag-outline` |
| 잠금 상태 등 운영 표시 | 범위 밖 (§5.4) |

### §4.5 흐림 처리 ✅

- 1점 카드: `opacity: 0.6` — 지금과 같다. **숨기지 않는다** (PRD §7.5).
- 필터 밖 항목(`전체 보기`): `opacity: 0.5` — 목업과 같다.

### §4.6 스켈레톤 🟡

판정 대기 중 배지 자리를 지키는 요소 ([badges.tsx:60](../src/components/badges.tsx:60)).
`surface` 채움 + `animate-pulse`, 높이는 배지와 같게 고정. 종이 위에서 회색 블록이 튀지 않도록 `neutral-200`(다크 `neutral-800`)까지만.

### §4.7 빈 상태 · 오류 🟡

박스를 두르지 않는다 (원칙 1). 가운데 정렬 대신 **왼쪽 정렬**, 위아래 `space-8` 여백.
제목은 `sub`(16px), 본문은 `small`(13px) `text-muted`.

## §5 화면별 적용

### §5.1 목록 `/` 🟡

```
┌ nav (1040px) ────────────────────────────────┐
│ 오늘공고            수도권 청년 지원정책…      │  .nav / .nav-brand
└──────────────────────────────────────────────┘
  ┌ 1040px ────────────────────────────────────┐
  │ 내가 신청할 수 있는 공고         [필터 적용│전체]│  title 25px / .seg
  │ 온통청년·정부24 총 N건 중, …                 │  small, text-muted
  │                                              │
  │ [해당 N] [애매 N] [아님 N]                   │  .tag 요약
  │                                              │
  │ [분야 칩…]  [검색] [출처▾] □전체 □스크랩     │  ListControls
  │                                              │
  │ ┌ .card elev-sm ──────────────────────┐     │
  │ │ 온통청년                    [5 신청 가능]│     │  kicker / 점수 배지
  │ │ 서울 청년 월세 지원사업              │     │  card-title
  │ │ 서울특별시 · 마감 2026-08-31         │     │  card-body
  │ │ [주거] [서울]                        │     │  .tag-neutral
  │ └──────────────────────────────────────┘     │
  │           ↕ gap-3 (15px)                     │
```

바뀌는 것:
- `border-b` 행 → **`.card` 그리드**, `gap-3`. 구분선 없음.
- 점수 배지는 **카드 오른쪽 위**로 (목업 배치). 지금은 제목 왼쪽에 있다.
- 출처 배지 → 카드 키커 (§4.2).
- 분야 칩(`ListControls`)은 `.tag-outline`(꺼짐) / `.tag-solid`(켜짐). 지금의 `bg-gray-900` 반전은 없앤다.
- `판정하기` 버튼 = `.btn-primary`. 이 화면의 유일한 채움 버튼이다.

### §5.2 상세 `/policies/[id]` 🟡

680px. 위에서부터: `← 목록으로`(`.btn-ghost`) → 제목 + 점수 배지 → 메타 한 줄 → 태그 → **판정 블록만 `.card`** → 원문(박스 없이 본문 그대로) → 신청 안내(박스 없이).

- 지금 `rounded border` 박스 네 개 중 **`.card`로 남는 것은 판정 블록 하나뿐**이다. 나머지는 제목 + 여백으로 나눈다 (원칙 1).
- 원문 블록은 `whitespace-pre-wrap`을 유지하고 행간만 1.7로.
- `원문 보기 ↗` = `.btn-secondary`, `스크랩` = `.btn-secondary`(해제 시 `.btn-ghost`).

### §5.3 프로필 `/profile` 🟡

680px. 각 `fieldset`은 `legend`(`sub` 16px) + 여백으로 구분 — 지금의 `border-t`는 저장 버튼 위 한 줄만 남긴다.
라디오·체크박스는 원본 `.radio`/`.seg` 문법으로. 현재의 테두리 라벨 묶음은 `.tag-outline` 형태의 선택 칩으로 바꾼다. ⬜ 정확한 형태는 §8.

### §5.4 관리자 `/admin` — 범위 밖 ✅

토큰만 상속한다 (색·서체·여백이 자동으로 따라온다). **레이아웃·표·막대 그래프는 건드리지 않는다.**
단, `gray-*`·`amber-*`·`red-*`·`green-*` 하드코딩은 남으므로 종이 배경과 어긋나 보일 수 있다 — 의도된 미완이다.

## §6 접근성 기준 ✅

### §6.1 대비

**측정값을 근거로 정한 규칙이다.**

| 조합 | 대비 | 판정 |
|---|---|---|
| `accent`(#0088b0) 채움 + 종이 글자 | 3.7:1 | ❌ 작은 글자 불가 → D4 |
| `accent-700`(#006786) 채움 + 종이 글자 | 5.7:1 | ✅ |
| `text-muted`(잉크 70%) on 종이 | 5.81:1 | ✅ |
| `text-muted`(잉크 70%) on 카드 `surface` | 5.59:1 | ✅ 카드 위에서도 통과한다 |
| `text-faint`(잉크 55%) on 종이 | 3.6:1 | ❌ 본문 불가 — 장식용만 |
| 점수 배지 5단계 | 5.72 ~ 9.85:1 | ✅ §4.1 표 참조 |

규칙:
1. **채움 배경 위 작은 글자는 `accent-ink`(700)를 쓴다.** `accent`는 링크·아이콘·테두리·큰 글자용.
2. **읽어야 하는 보조 텍스트는 `text-muted`(70%)까지만.** 원본의 `.card-meta`(50%)·`figcaption`(55%)은 이 프로젝트에서 70%로 올린다.
3. 본문 크기의 accent 텍스트는 라이트에서 `accent-700`, 다크에서 `accent-300`.

### §6.2 색에만 기대지 않는다

점수 배지는 **숫자 + 말**을 함께 적는다 (`5 신청 가능`). 이미 그렇게 되어 있고 ([badges.tsx:47](../src/components/badges.tsx:47)), 잉크 농도 계단(§4.1)이 색과 독립된 두 번째 단서다.

### §6.3 포커스

`:focus-visible { outline: 2px solid var(--color-accent); outline-offset: 2px }`.
**기본 파란 링을 남기지 않는다.** 세그먼트 컨트롤 안쪽 요소만 `outline-offset: -2px`.

## §7 결정 기록

| 결정 | 대안 | 왜 이쪽인가 |
|---|---|---|
| 다크 모드 유지 | 라이트 전용 (원본 그대로) | 사용자 결정. 토큰이 뒤집히므로 컴포넌트 코드는 오히려 단순해진다 (`dark:` 전부 삭제) |
| Noto Serif KR 페어링 | Pretendard 등 산세리프 / 나눔명조 | 원칙 2를 지키면서 한글이 읽힌다. 나눔명조는 12px 배지에서 흐려진다 |
| `@theme` + 얇은 레이어 | 원본 CSS 통째 이식 | Tailwind와 두 체계가 공존하면 어느 쪽이 이기는지 매번 확인해야 한다 |
| `--spacing: 5px` | 여백을 개별 매핑 | 한 줄로 기존 유틸리티 전부가 목업 밀도가 된다. 우연이 아니라 density 1.25×의 정의다 |
| 점수 = 잉크 농도 | 5색 팔레트 | 원본은 잉크가 세 개뿐이다. 농도는 색맹에게도 순서가 남는다 |
| 출처를 색으로 안 나눔 | 소스별 색 유지 | 색이 늘면 판정 배지가 묻힌다. 목업이 이미 키커로 답했다 |
| 채움 잉크 `accent-700` | 원본 `accent` 그대로 | 3.7:1은 작은 글자 AA 미달. 눈으로는 거의 같은 시안이다 |
| `/admin` 제외 | 전부 적용 | 운영용 내부 화면. 사용자 화면 일관성이 먼저다 |
