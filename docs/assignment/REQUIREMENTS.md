앞선 두 프로젝트는 "무엇을 만들지"가 정해져 있었지만, 
마지막 프로젝트는 시작부터 여러분이 정합니다. 이전 수업에서 작성한 기획서를 살펴보고 구체화 하여 구현합니다.

## 1. 배경과 목적

상세한 기획서를 바탕으로 여러분만의 AI Agent 웹 서비스를 완성합니다.

<aside>
🎯

**먼저 작게 완성하는 것을 목표로 하세요.**

기능이 많은 서비스가 아니라 하나의 일을 확실히 해내는 서비스가 좋은 평가를 받습니다. 
화면 3개짜리 서비스가 완성되는 것이, 화면 10개짜리가 절반만 되는 것보다 훨씬 낫습니다.

</aside>

## 2. 시스템 구성

각자 본인 계정으로 Vercel과 Supabase 프로젝트를 만들어 사용합니다.

```
[사용자] ── 브라우저로 접속
    │
    ▼
┌─────────────────────────┐
│   Next.js (Vercel 배포)   │
│                         │
│   화면 + 서버 로직         │
└─────────────────────────┘
      │              │
      │              │ AI 호출
      │              ▼
      │        ┌───────────┐
      │        │  LLM API  │
      │        └───────────┘
      │
      │ 저장 / 조회
      ▼
┌─────────────────────────┐
│       Supabase          │
│   데이터베이스 (+ 인증)     │
└─────────────────────────┘
```

**기술 스택 (고정)**

| 구분 | 사용할 것 |
| --- | --- |
| 프레임워크 | Next.js |
| 배포 | Vercel |
| 데이터베이스 | Supabase |
| AI | Gemini API 사용
(LLM, 이미지 생성 등) |

## 3. 요구사항

### REQ-01 :: 주제 (자유)

기존에 작성한 **기획서를 기반으로** 주제를 정합니다.

- 기획서를 그대로 만들어도 되고, 이틀 안에 만들 수 있는 크기로 줄여도 됩니다.
- 줄였다면 **무엇을 뺐는지와 그 이유**를 제출 문서에 적습니다. 범위를 줄이는 것은 감점이 아니라 설계 능력입니다.
- 프로젝트 1, 2와 주제가 겹쳐도 괜찮습니다. 단, n8n으로 만든 것을 웹으로 옮기는 것이라면 **웹이기 때문에 가능해진 것**이 있어야 합니다.

### REQ-02 :: AI 기능 (1개 이상 필수)

서비스 안에 **AI가 실제로 동작하는 기능이 최소 1개** 있어야 합니다.

- 사용자의 입력이나 데이터를 받아 AI가 처리하고, 그 결과가 화면에 나타나야 합니다
- 미리 만들어 둔 응답을 보여주는 것은 AI 기능이 아닙니다.

<aside>
💡

**AI 기능 예시** :: 사용자가 쓴 글을 분류하거나 요약하기, 입력을 바탕으로 추천하기, 자연어 질문을 검색 조건으로 바꾸기, 이미지나 문서에서 정보를 뽑아내기, 대화형으로 응답하기 등. 

</aside>

### REQ-03 :: 데이터 저장 (Supabase)

사용자가 만든 데이터나 AI 처리 결과가 Supabase에 저장되어야 합니다.

- 새로고침하면 사라지는 상태는 저장이 아닙니다. 브라우저를 껐다 켜도 남아 있어야 합니다
- 최소 1개 이상의 테이블을 설계합니다.
- 로그인 기능은 필수가 아닙니다. 
다만 사용자별로 데이터가 구분되어야 하는 서비스라면 Supabase 인증을 쓰는 편이 빠릅니다.

### REQ-04 :: 배포 (Vercel)

**접속 가능한 주소**가 있어야 합니다.

- 링크를 받은 사람이 아무 설치 없이 바로 쓸 수 있어야 합니다.
- 제출 전에 **다른 기기나 시크릿 창으로 직접 열어보세요.** 본인 브라우저에서만 되는 경우가 자주 있습니다.

### REQ-05 :: 최소한의 사용성

만든 사람이 아니어도 쓸 수 있어야 합니다.

- 처음 들어온 사람이 **무엇을 하는 서비스인지, 무엇을 먼저 눌러야 하는지** 알 수 있어야 합니다
- AI 호출이 실패하거나 입력이 비었을 때 화면이 깨지지 않아야 합니다.
